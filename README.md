# 📘 JavaScript Theory Assignment 3

A collection of fundamental JavaScript concepts explained with simple definitions and practical code examples.

## 📌 Topics Covered

This assignment covers the following topics:

1. **Frontend vs Backend JavaScript** — Understanding their roles and differences.
2. **DOM (Document Object Model)** — Accessing and manipulating webpage elements.
3. **JavaScript Events** — Handling user interactions.
4. **Event Loop** — Understanding JavaScript's asynchronous execution.
5. **Hoisting** — How JavaScript handles declarations.
6. **Event Bubbling** — Understanding event propagation in the DOM.
7. **Types of Functions** — Named, anonymous, and arrow functions.
8. **Loops** — Using `for...of` and `for...in`.
9. **Array Methods** — Exploring `push()`, `pop()`, `map()`, `filter()`, and `reduce()`.
10. **Callback Functions** — Passing functions as arguments to other functions.

## 🎯 Objective

To understand the core concepts of JavaScript, strengthen programming fundamentals, and learn how these concepts are used in web development.
